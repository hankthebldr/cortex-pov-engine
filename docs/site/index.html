Clone and build

CortexSim is distributed as source. There is no tagged release and no published container image — the release pipeline exists in .github/workflows/release.yml and fires on a v*.*.* tag, but no tag has been cut. Everything you run comes from the tree.

Docker canonical local bring-up 
git clone https://github.com/__GH_OWNER__/__GH_REPO__.git
cd __GH_REPO__
cp .env.example .env
./scripts/dev-up.sh

Builds the image and brings SimCore up on :8888.

No Docker sandboxed runners, dev containers 
./scripts/dev-up-native.sh              # full bring-up
./scripts/dev-up-native.sh --skip-ui    # reuse core/static/
./scripts/dev-up-native.sh --stop       # stop

Generates .env, builds the venv and the React UI, polls /api/health.

Full jumpbox bootstrap (Ubuntu 22.04 / Debian 12) 
git clone https://github.com/__GH_OWNER__/__GH_REPO__.git
cd __GH_REPO__
./install.sh

System deps, submodules, Go beacon, Rust tools, React build, compose up.

Enroll a beacon on a target host 
curl -fsSL '<server>/api/agents/install?os=linux' | CORTEXSIM_TOKEN='cxs_…' bash

Needs no Go toolchain and no public-internet egress on the target — the beacon is downloaded from your own SimCore and sha256-verified. Installs a systemd unit or launchd job by default.

Proof, not claims

This project refuses to report three different things as one number. A scenario that loads is not a scenario that ran, and a scenario that ran against a mock is not evidence about a customer's tenant.

RungWhat it provesWhat it does notCount
Authored The artifact exists and loads clean under strict validation. That it has ever executed. 170 + 20
Configured A tenant credential is present in the encrypted vault. That the tenant is reachable. —
Reachable Preflight resolved DNS/TLS, auth, scope, datasets and clock skew. That any detection fired. —
Verified A run executed against a live tenant and the alert was read back. — 0

Tenant-verified is 0. No run and no assertion in this repository has ever executed against a live Cortex tenant. Every green in the test suite and in the console comes from an injected transport. Authored is not proven — the console's Readiness surface states this verbatim, and every preflight response carries queries_issued so a mocked green cannot be quoted as tenant proof.

UC/TC aligned

Every scenario maps to MITRE ATT&CK and to a validated foreign key in the FY27 v2.2 index — 266 test cases, enforced at load time. Not a generic atomic test.

Survives default-deny

The payload shelf stages digest-pinned tool artifacts on your own SimCore, so a blocked download can't masquerade in a POV report as “Cortex missed it.”

Measured, not ticked

Opt-in, read-only alert read-back auto-validates seeded results into evidence-backed MTTD. SimCore never writes to Cortex.
