02

Run it

Tagged GitHub Releases: installer, five beacon builds (unsigned), SHA256SUMS, manifest.json. Build the image from the tree.

Docker

git clone https://github.com/__GH_OWNER__/__GH_REPO__.git
cd __GH_REPO__
./scripts/dev-up.sh            # writes .env with a fresh secret

No Docker

./scripts/dev-up-native.sh

Enroll a beacon

# Linux or macOS
curl -fsSL '<server>/api/agents/install?os=linux' | CORTEXSIM_TOKEN='cxs_…' bash

# Windows, elevated PowerShell
[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor 3072; $env:CORTEXSIM_TOKEN='cxs_…'; iwr -useb "<server>/api/agents/install?os=windows" | iex

# Kubernetes
kubectl apply -f '<server>/api/agents/manifest'

The console's Get started prints these with your server and a token. The target needs no Go toolchain and no internet egress.
