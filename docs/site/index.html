Execution paths

cortexsim-agent on Linux, macOS or Windows. Runs as a service.

Push bundle
bash, PowerShell 5.1 or K8s YAML. Runs offline.
GET /api/scenarios/{id}/download?format=

The beacon hands EAL steps to SimCore. Collector steps go from SimCore; network steps run from the endpoint.

04

Read-back

How POVengine measures what Cortex saw. Read-only, and off until a credential is set.

Alert read-back
The run endpoint's alerts, matched to expected detections. Gives MTTD. The console's Review.
POST /api/runs/{id}/reconcile?connector=xsiam
Manual alerts
Exported alerts, pasted in. Works offline.
POST /api/runs/{id}/observations
XQL verify
Read-only XQL per test case. Needs the xql capability.
POST /api/runs/{id}/verify
Tenant evidence
Issues, cases and the endpoint record for one run. Context only.
POST /api/runs/{id}/tenant-evidence
Case ledger
Which cases the matched alerts landed in.
POST /api/runs/{id}/case-ledger/refresh
Tenant preflight
Per credential: DNS/TLS · auth · scope · datasets · clock · response layer.
POST /api/connectors/{kind}/preflight
NGFW preflight
PAN-OS, read-only: log forwarding (SLS, syslog), EAL, decryption, clock; NAT and shared source per agent.
POST /api/connectors/panos_ngfw/preflight
Collector check
Configured → reachable → accepted; then whether tagged records arrived.
POST /api/collector-targets/{name}/preflight · /arrival

06

Run it

Tagged GitHub Releases: installer, five beacon builds (unsigned), SHA256SUMS, manifest.json. Build the image from the tree.

Docker

git clone https://github.com/__GH_OWNER__/__GH_REPO__.git
cd __GH_REPO__
./scripts/dev-up.sh            # writes .env with a fresh secret

No Docker

./scripts/dev-up-native.sh

Enroll a beacon

# Linux or macOS
curl -fsSL '<server>/api/agents/install?os=linux' | CORTEXSIM_TOKEN='cxs_…' bash

# Windows, elevated PowerShell
[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor 3072; $env:CORTEXSIM_TOKEN='cxs_…'; iwr -useb "<server>/api/agents/install?os=windows" | iex

# Kubernetes
kubectl apply -f '<server>/api/agents/manifest'

The console's Get started prints these with your server and a token. The target needs no Go toolchain and no internet egress.
